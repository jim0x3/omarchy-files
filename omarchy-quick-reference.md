## omarchy-quick-reference

| Shortcut                                          | Action / Description                                          |
| ------------------------------------------------- | ------------------------------------------------------------- |
| **System & Launcher**                             |                                                               |
| `Super + Space`                                   | Reveal the Omarchy Menu                                       |
| `Super + Return`                                  | Launch the terminal                                           |
| `Super + Shift + Return`                          | Launch the web browser                                        |
| `Super + Ctrl + T`                                | Open Activity Monitor (starts floating)                       |
| `Super + Shift + F`                               | Open the File Manager                                         |
| `Super + W` or `Super + Q`                        | Close the focused window                                      |
| `Ctrl + Alt + Delete`                             | Close all open windows                                        |
| **Focus & Navigation**                            |                                                               |
| `Super + Arrow`                                   | Move focus to adjacent window (centers cursor on it)          |
| `Super + Left Click + Drag`                       | Move/rearrange a window with the mouse                        |
| `Super + Right Click + Drag`                      | Freely resize a window with the mouse                         |
| **Tiling & Window State**                         |                                                               |
| `Super + J`                                       | Toggle window split between stacked and side-by-side          |
| `Super + Shift + Right Arrow`                     | Swap active window position                                   |
| `Super + T`                                       | Toggle window between floating and tiled                      |
| `Super + F`                                       | Toggle true fullscreen                                        |
| `Super + Alt + F`                                 | Toggle full-width view (preserves top bar)                    |
| `Super + Ctrl + F`                                | Toggle fullscreen contained within the window                 |
| `Super + L`                                       | Toggle current workspace layout between Dwindle and Scrolling |
| `Super + O`                                       | Pin/pop floating window to follow across all workspaces       |
| **Workspaces**                                    |                                                               |
| `Super + Shift + <NUMBER>`                        | Move active window to workspace `<NUMBER>` and switch to it   |
| `Super + Shift + Alt + <NUMBER>`                  | Silently move active window to workspace `<NUMBER>`           |
| **Window Grouping**                               |                                                               |
| `Super + G`                                       | Create a new group or disassemble the current group           |
| `Super + Ctrl + Left/Right Arrow`                 | Cycle through windows inside the active group                 |
| `Super + Alt + 1/2/3/4`                           | Jump directly to numbered window within the active group      |
| `Super + Alt + G`                                 | Move the focused window out of the group                      |
| `Super + Alt + Arrows`                            | Pull an outside window into the active group                  |
| **Scratchpad**                                    |                                                               |
| `Super + Grave ( \` )`or`Super + S`               | Toggle the dropdown scratchpad workspace                      |
| `Super + Shift + Grave ( \` )`or`Super + Alt + S` | Move the active window into the scratchpad                    |
